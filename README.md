# 拾遗周刊

记录技术、产品与生活里值得留下来的东西。

- Website: https://weekly.yano.blog
- Blog: https://yano.blog
- X: https://x.com/yano82895800

## Development

```bash
pnpm install
pnpm dev
```

构建：

```bash
pnpm build
```

文章放在 `src/pages/posts/` 下，文件名建议使用：

```text
01-新的开始.md
02-标题.md
```
